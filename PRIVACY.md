# Privacy Policy

**Auto Viral Media Engine** is a personal automation tool that publishes content to YouTube and Instagram.

## Data Collection
This application does **not** collect, store, or share any personal data from end users.

## OAuth & API Usage
- **Google / YouTube OAuth:** Used solely to upload videos to the owner's own YouTube channel. No data is shared with third parties.
- **Instagram API:** Used solely to publish Reels to the owner's own Instagram account.
- **Pexels & TMDB APIs:** Used to fetch royalty-free video clips and movie metadata. No personal data is transmitted.

## Data Storage
All data (SQLite databases, log files, credentials) is stored locally on the owner's private server and is never shared.
